## First-month measurement

Targets are experiment thresholds, not forecasts: five outside demo completions, three substantive feedback reports, one independent reference.

Review once a week. Record channel, date, public URL, status, referrals if available, voluntary completions, and useful feedback. Use unavailable for missing metrics; do not substitute zero. GitHub referrals and skills.sh counts are incomplete proxies for use. Never collect statement data for analytics.

If there are no visits, revise the hook/channel. If visits fail to become completed demos, repair the observed setup friction. If demos complete but users find little value, revise the use case before expanding distribution.
